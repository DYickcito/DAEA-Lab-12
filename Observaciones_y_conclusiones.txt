OBSERVACIONES Y CONCLUSIONES
Proyecto: API REST Uma Salud

OBSERVACIONES

1. Durante el desarrollo se implementó una API REST con ASP.NET Core Web API, organizada en controladores, modelos y un contexto de base de datos.

2. Se utilizó Entity Framework Core para conectar la aplicación con SQL Server y realizar operaciones sobre los datos.

3. La API permite registrar, consultar, actualizar y eliminar especialidades y pacientes mediante los métodos HTTP GET, POST, PUT y DELETE.

4. Se aplicaron validaciones y reglas de negocio para evitar datos duplicados y mantener la relación entre pacientes y especialidades.

5. Swagger facilitó la documentación y las pruebas de los endpoints de la API.

6. El despliegue en MonsterASP.NET permitió comprobar que la API puede conectarse a una base de datos alojada en la nube.

CONCLUSIONES

1. Se desarrolló una API REST funcional que permite administrar la información de un centro de salud ficticio.

2. ASP.NET Core Web API, junto con Entity Framework Core, facilitó la creación de servicios y el acceso a una base de datos relacional.

3. La organización del proyecto en modelos, controladores y contexto ayuda a mantener el código ordenado y facilita futuras modificaciones.

4. Las validaciones y restricciones de la base de datos son importantes para conservar la integridad de la información.

5. El proyecto permitió poner en práctica el proceso completo: desde el diseño de las entidades y la implementación de los endpoints hasta las pruebas y el despliegue en la nube.
